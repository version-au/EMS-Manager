Schedules

How schedules work

Each schedule is applied while it's active, and re-applied automatically if something else changes the values during that window. Power fields are entered in kW and converted to each entity's own unit (W or kW). When two active schedules overlap, whichever is lower in the list wins on any field they both set; use Reorder to change the order. The On/Off switches and reordering save straight away. Everything else is saved from each schedule's own editor, so tap a schedule (or a block on the timeline) to open it.
